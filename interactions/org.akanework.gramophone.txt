# Gramophone: playback, pause and skip-to-next from the Songs list.
# - The androidx.media3 session posts events on play; ATL's
#   MediaSession.sendSessionEvent used to be missing (NoSuchMethodError killed
#   Gramophone via its own crash handler - witnessed on the phone desktop log,
#   2026-11-22, and reproduced with this script as bazzite run gpre1, fixed
#   run gpost1).
# - The skip step (opus -> FLAC library item) exercises the AudioTrack
#   pause/flush/stalled-write fixes and the FLAC decoder: before those,
#   Gramophone's onTracksChanged saw an unselected track group and stopped the
#   player (witness bazzite gpost7/gpost11; verified fixed in gpost12).
# Needs the harness test library ([atl] media_dir,
# scripts/runner/make-test-media.sh); on runners without it this just fails
# the taps harmlessly. 1080x1920 screen.
#
# NOT P2-convertible: Gramophone's list is androidx Compose (one opaque
# AndroidComposeView node in the element dump), so named finds have nothing
# to match until the P3 accessibility pass (docs/agent-tasks/
# element-addressed-interaction.md). The coordinate taps here are
# known-fragile (see that brief's "Why").
wait 3
expect-text "Songs"
tap 64 336      # play icon on the first song row (Alpha Song 1, opus)
wait 6
shot playing
tap 64 336      # same icon is pause while playing
wait 3
shot paused
tap 610 401     # Beta Tune 1 (FLAC): skip starts it; must show pause icon
wait 4
shot after_skip
tap 610 401     # pause Beta
wait 2
tap 610 401     # resume Beta: sink re-prepare must complete
wait 3
shot after_resume
